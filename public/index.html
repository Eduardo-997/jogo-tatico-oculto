Modo solo contra IA. Informações da peça ficam fixas ao lado do tabuleiro; o pacote também inclui X1 em servidor.
X1
🔒 IA isolada do mapa completo
A IA roda em outro contexto (Web Worker) e recebe somente um snapshot filtrado da própria visão.
IA recebe:
✓ suas próprias peças, posições e status
✓ rodada / turno / perdas públicas
✓ inimigos SOMENTE quando legalmente revelados
✓ percepção como verdadeiro/falso, sem coordenada escondida
✓ informações públicas necessárias

IA NÃO recebe:
✗ array interno das peças do jogador
✗ coordenadas ocultas do jogador
✗ espelhos ocultos adversários
✗ estado completo do Árbitro
✗ acesso ao DOM/tabuleiro visual

Fluxo: UI → Árbitro → snapshot filtrado → Web Worker IA → intenção → Árbitro resolve.
